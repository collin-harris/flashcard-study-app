Binary search works on a sorted sequence by repeatedly comparing the target with the middle element and discarding half of the remaining search interval.
```python
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target: return mid
        if a[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1
```
The loop runs in O(log n) time in the usual random-access array model. The input must be sorted for these comparisons to justify discarding half the interval.
